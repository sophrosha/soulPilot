## 1. Что сделано (правки после первого теста)

- **Звук — НЕПРЕРЫВНЫЙ ЛУП** (было «с перерывами» каждые 1.5 с):
  GE `petSoundStart/Stop`: `Engine.Audio.createSource('AudioGui', event)` +
  `source:play(1, 1)` — бесконечная петля; стоп с fade 1 с — при завершении
  (6 с), `apl_pet("off")`, guard-отказе vehicle (колбэки
  onVehiclePetDone/onVehiclePetRejected) и смене миссии. «Дыхание» —
  осцилляция громкости в GE onUpdate (breath_hz 0.3, depth 0.25, ±12.5%),
  база volume 1.0 (посильнее). ОГРАНИЧЕНИЕ движка: pitch живого лупа из Lua
  не меняется (у SFXObject нет setPitch — проверено по исходникам main.lua/
  audioEventsList.lua), поэтому «дыхание» громкостью, а не питчем; питч 0.7
  подставляется best-effort при createSource (если API принял — иначе родной
  тембр события, который игрок и так выбрал в SFX Previewer).
- **Педаль — ДРОЖАНИЕ 0.0..0.3** (было прыжки к максимуму): теперь
  `throttleOverride = env * (offset 0.15 + amp 0.15 * sin(2π·2.5Гц·t))` —
  мелкая вибрация на малых оборотах; env — плавный вход 0.5 с + спад в
  последние 25%.
- **ТОРМОЗ ЗАЖАТ** (главное: коробка видела газ → сцепление → машина ехала):
  пока эффект активен — `electrics.values.brakeOverride = 1.0` (полный
  тормоз, ставится сразу при старте); по завершении/off/respawn — nil.
  Машина стоит, «урчит и дрожит педалью».
- `pet.json`: throttle { offset 0.15, amp 0.15, hz 2.5 }, sound { pitch 0.7,
  breath_hz 0.3, breath_depth 0.25, volume 1.0 }; поля interval_s/wobble
  удалены (звук больше не «пыхтения»).
- Проверки: lua_block_balance OK (main/pet/wheel), pet.json валиден (14 полей).

## 3. ТЕСТ (выполняет игрок, повторный прогон)

И в момент поглаживания AI реально ведёт машину (например, медленное
торможение к светофору, <5 км/ч). На полной стоянке wheel не перезаписывает
руль (штатное поведение Фазы 4).

1. `apl_debug()`.
2. Спавн Bolide, мотор заведён, машина стоит.
3. `apl_pet("status")` — печать конфига (дрожание/тормоз/руль/звук/гейт).
4. `apl_wheel("on")`.
5. `apl_pet("on")` — ожидаем:
   - `aplPet: ПОГЛАЖИВАНИЕ НАЧАТО (6 с, дрожание газа 0.15+±0.15 @ 2.5 Гц,
     тормоз зажат, руль ×0.50)`;
   - `apl_pet: звук мурчания — НЕПРЕРЫВНЫЙ ЛУП: event:>Engine>Shutoff>v8_20xy_eng
     (дыхание громкости 0.30 Гц)`;
   - ощущения: **машина НЕ уползает** (тормоз зажат), педаль газа/обороты —
     мелкое частое дрожание (~2.5 колебания/сек), звук — НЕПРЕРЫВНОЕ утробное
     урчание с «дыханием» (то громче, то тише), без пауз.
6. В конце (6 с): `ПОГЛАЖИВАНИЕ ЗАВЕРШЕНО — газ/тормоз возвращены`; звук

7. Повторный on в середине — отказ «уже идёт» (луп гаснет — rejected).
8. `apl_pet("off")` в середине — мгновенно: «ПОГЛАЖИВАНИЕ ПРЕРВАНО», звук
