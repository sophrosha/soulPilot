## 2. Перелом «плавно → резко» (P1): t≈46.9–47.8

- max |d(thr_sm)/dt| = 0.36 ед/с; **НИ ОДНОЙ строки |rate|>0.5**; НИ ОДНОГО
  торможения (brake_rows=0).
- Плавный старт-кап (0.45) действовал t=28–35 (factor 0.45→1), после — снят,
  но raw тоже шёл плавно.
- 5-с окна: t25-30 → 0.09, t30-35 → 0.36, t35-40 → 0.36, t40-45 → 0.11.

**Момент перелома:**
- Первый срез газа: **t=46.94** (rate −0.54 ед/с), углубляется: t=47.22 (−0.81),
  t=47.82 (−1.00); первый raw-cut < −1.0: t=47.60.
- **Первое торможение в поездке: t=47.98 (brake_raw 0.41)**, в окне t45-50
  пик 0.51.
- Контекст в момент перелома: **gear=5, speed=20.56 м/с (пик прогона ~21.6 =
  целевая скорость AI на участке), rpm≈1471, clutch=0, acc +1.48** (машина ещё
  разгонялась) — AI достиг скорости и начал «пилить» вокруг цели.

**После перелома (t=47.8–151.2, engaged):** 112 строк |rate sm|>0.5 (против 0
до), max |rate sm| в 5-с окнах до 2.00, тормозных строк 227, срезы raw до

(окна t55-60 → 1.47, t60-65 → 1.86, t75-80 → 1.83, t85-90 → 1.04,

**Вердикт: перелом = первый цикл круиз-логики AI (разогнался до цели →
сброс+тормоз). «Резкость» для игрока — чередование срезов и возвратов газа
(raw скачет 0↔1). Наш конвейер сглаживает: восходящие скачки сглаженного газа
≤ +0.36 ед/с (throttle_rise 2.0 не добирается — реально лимитирует ema/lerp),
нисходящие ограничены throttle_fall 3.0 ед/с. Характер пилы — ванильный.
НЕ баг модуля.**

## 3. Clutch: гипотеза (B) «КПП при переключении» — ЧАСТИЧНО подтверждена

Эпизоды clutch_raw>0.1 по всем прогонам (gear-adjacency = смена передачи в
±4 строки вокруг эпизода):

| Прогон | Эпизод | Длит. | Gear | Shift? | Примечание |
|---|---|---|---|---|---|
| P1 (ON) | t=141.48–144.63 | 3.2 с | 3→[3]→3 | **НЕТ** | rpm 2640→2676 (около лимитера T-Series), speed 12.9→10.8 при thr=1.00 (разрыв тяги), jerk при возврате +4.2 |
| Контроль (ON) | t=48.18–48.90 | 0.7 с | 3→[3,0]→4 | **ДА** | jerk_post=3.1 |
| 4.7-B (OFF) | t=155.38–160.08 | 4.7 с | 0→[0,4]→4 | **ДА** | старт с места, jerk_post=3.8; +4 импульса на месте |
| 4.8 (OFF) | t=76.92 / 145.62 / 159.16 | 0.1–0.3 с | 4→[4]→4, 5→[5]→5 | НЕТ | короткие |
| 4.8 (OFF) | t=219.52–221.31 | 1.8 с | 5→[5]→5 | НЕТ | rpm 1118→2596 свободная раскрутка при thr=0.06 |

Строк clutch>0.1: 4.7-B — 95, 4.8 — 77, P1 — 51, контроль — 16.

**Вердикт:**
- Часть clutch-эпизодов СОВПАДАЕТ со сменой передач (контроль 3→4, 4.7-B 0→4)
  — это ванильная КПП размыкает сцепление на переключении. Гипотеза (B)
  подтверждена для этих эпизодов.
- Часть — размыкания БЕЗ смены передачи (P1: 3.2 с на 3-й при полном газе;
  4.8: 1.8 с на 5-й при почти нулевом газе). **Но такие же эпизоды ЕСТЬ в
  OFF-прогонах (4.8), где модуль пассивен и clutchOverride не пишется вовсе**
  → это ванильное поведение трансмиссионного стека Gavril (два диапазона /
  автомат / защита), НЕ наш модуль. Для P1 это означает: 3.2 с разомкнутого
  сцепления при полном газе → разрыв тяги, замедление 12.9→10.8, rpm на
  лимитере, jerk +4.2 при возврате — вот и ощущение «сцепление будто выжал
  кто-то».
- **Наш модуль — только эхо:** `cltOut = clamp01(cltRaw); >0 → clutchOverride
  = echo (1 кадр латентности), иначе nil`. Чекер 5г′ в ОБОИХ прогонах (P1 и
  контроль): **0 лагов, max |clutch_sm − raw| = 0** в engaged — passthrough
  валидирован данными. Нулевой вред доказан OFF-прогонами (те же пульсы).
- **Оговорка: комментарий в коде «AI НИКОГДА не пишет clutch, input — всегда
  игрок» — ОПРОВЕРГНУТ данными** (clutch-эпизоды при AI-движении в OFF-
  прогонах; игрок в этот момент педаль не нажимал — пишет ванильный
  трансмиссионный контроллер/AI-логика). Фикс комментария — ТОЛЬКО по
  согласованию координатора.
