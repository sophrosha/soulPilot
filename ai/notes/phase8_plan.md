# ФАЗА 8 «Pop-up фары / Глазки» — ПЛАН (2026-10-19)

Статус: ПЛАН РАЗРАБОТАН, КОД НЕ ПИСАЛСЯ. Нужно утверждение координатора.
Машины: ТОЛЬКО Civetta Bolide и Ibishu Wigeon (проверка по JBeam-ключу).
Активация: ТОЛЬКО командой игрока (`apl_popup("auto")`), авто-режимов нет.

## 1. Исследование (найдено в исходниках 0.39.4)

### 1.1 Как устроены pop-up фары (главная находка)
Выезд фар — это **гидравлики (hydros) в JBeam**, привязанные к electrics-
переменной `lowhighbeam`:
- `vehicles/bolide/bolide_headlights.jbeam` (распакован из content/vehicles/
  bolide.zip), секция `"hydros"`:
  `["fe18r","he2r", {"inputSource":"lowhighbeam","inLimit":0,"outLimit":1.43,
  "inRate":1,"outRate":1,"inputFactor":1}]` — L/R (строки 162-163, 337-338).
- `vehicles/wigeon/wigeon_headlights.jbeam`: то же самое,
  `outLimit: 1.3` (строки 146, 311). **У Wigeon тоже pop-up** (обе модели из
  `lights.json guard.popup_models` подходят).
- Т.е. hydro физически двигает узел фары при `electrics.values.lowhighbeam > 0`.
  Скорость выезда/заезда задана ванилью (`inRate/outRate = 1` — плавный ход
  ~1.4 с), нам НЕ нужно управлять плавностью самим.

### 1.2 Связь выезда и света
- `lowhighbeam` формируется в ванили как
  `vals.lowhighbeam = (lightsState == 1 or lightsState == 2)`
  (`lua/vehicle/electrics.lua:433`), пересчёт КАЖДЫЙ кадр.
- Свет (filament `lowbeam_filament`/`highbeam_filament` → glowMap материалов)
  включается тем же `lightsState` (`electrics.setLightsState`, electrics.lua:1026).
- **Вывод**: выезд фар и свет — жёстко связаны ванилью и НЕ разделяются
  штатными средствами: свет включён → фары выеханы и светят; выключен →
  заеханы. Значит **правило безотказности ночью выполняется самой ванилью**:
  при включении света фары выезжают ОДИН раз и остаются (пока свет включён),
  без дребезга «фулл→выкл→фулл».

### 1.3 Что уже есть в моде
- `playerJBeam(veh)` — определение JBeam-ключа машины (GE main.lua, уже
  используется в pop-up guard Фазы 6).
- `lights.json guard.popup_models = ['bolide','wigeon']`,
  `refuse_auto_on_popup = 1` — сейчас `apl_lights("auto")` на этих моделях
  ОТКАЗЫВАЕТ (Фаза 6, строка ~1311).
- Ф6-логика ночи/дня в GE: `lightsIsNight` / `day_state` / `night_state`.
- Паттерн «ручное вмешательство → авто-отключение» — отработан в Фазе 6.

## 2. Дизайн

### 2.1 Команда и конфиг
- `apl_popup("auto")` — включить авто-моргание; `apl_popup("off")` — выключить
  (и вернуть глазки в штатное состояние: если свет включён — остаются
  выеханными, ничего не трогаем); `apl_popup("status")` — состояние.
  По умолчанию — ВЫКЛ, без команды фича не работает.
- Конфиг `ai/config/popup.json` (правки без кода): интервалы дня/ночи,
  длительность моргания, вкл/выкл по умолчанию.

### 2.2 Логика моргания («глазки»)
- Случайный интервал между морганиями: **днём 120–180 с (чаще),
  ночью 180–300 с (реже)** (по ТЗ «или наоборот» — подтвердить).
- Моргание = ОДИН цикл без лишних переключений: `setLightsState(1)` →
  пауза `blink_s` (~1.5–2 с, пока hydro выезжает) → `setLightsState(0)`.
  Глазки выезжают и заезжаются один раз, как живые.
- **Подавление ночью**: если свет СЕЙЧАС включён (глазки уже выеханы) —
  моргание НЕ запускается (иначе был бы запрещённый «фулл→выкл→фулл»:
  выеханные фары заехались бы и выехали снова). Моргаем только когда свет
  выключен. Ночью при включённом свете авто-моргание просто молчит —
  глазки и так «живые» (ванильный выезд при включении света — один раз).
- Первое моргание — через полный случайный интервал после `auto` (не сразу).

### 2.3 Ручное вмешательство
- Если игрок сам меняет свет (радиал-меню/клавиши) не в момент нашего
  моргания — расхождение `lights_state` с нашим ожидаемым следом →
  `auto OFF` + WARN «Ручное управление, авто-режим отключен» (паттерн Ф6).

### 2.4 Сторонние эффекты
- Моргание дёргает штатный `electrics.setLightsState` — тот же API, что в
  радиал-меню и Ф6 (БЕЗ input.event, БЕЗ toggle-цикла).
- Свет Ф6 (`apl_lights auto`) на Bolide/Wigeon: guard `refuse_auto_on_popup`
  **СНЯТ 19.10 (решение координатора)** — авто-свет Ф6 работает, ночью фары
  выедет САМ Ф6 (один ванильный выезд, глазки живут). Ф6 и Ф8 уживаются:
  перед мигком Ф8 ставит `autopilotLiveLightsCmd.setSuppress(true)` (Ф6 молчит
  и не считает мигок ручным вмешательством), переходы Ф6-auto Ф8 отличает
  через `isAuto()` — это НЕ вмешательство.

## 5. Тест (после кода)

### 5.1 Быстрый тест моргания (БЕЗ ожидания 2 минут)
1. В `ai/config/popup.json` поставить `"debug_force_blink_delay_s": 5`
   (сохранить файл; конфиг читается при `apl_popup("auto")` — перезапуск
   игры не нужен, только новая команда).
2. `apl_debug()`, спавн **Bolide**, свет ВЫКЛЮЧЕН.
3. `apl_popup("auto")` — включился, «первый миг через 5 с».
4. Ждать ~5 с: глазки выезжают и заезжаются ОДИН раз (моргание), каждые 5 с
   повтор (ТЕСТ-РЕЖИМ: все интервалы = 5 с).
5. `apl_popup("status")` — active/phase/timer/интервалы.
6. Проверить подавление: в момент, когда глазки открыты, НЕ моргать ещё раз
   (один цикл), при включённом свете — моргания нет вовсе.
7. Вернуть `"debug_force_blink_delay_s": 0` — нормальный режим (120–180 с).

### 5.2 Полный чеклист
1. `apl_debug()`, спавн Bolide, `apl_popup("status")` — авто выключен.
2. `apl_popup("auto")` (свет выкл) — включился; при debug=0 глазки моркают
   через 120–180 с (один выезд-заезд), лог `aplPopup: МОРГАНИЕ ...`.
3. Ночь (`setTimeOfDay('21:00')`/ждать): включить свет — глазки выезжают
   ОДИН раз и остаются (моргание подавлено, «фулл→выкл→фулл» НЕТ); смена
   дня/ночи видна в `apl_popup("status")` и логе `popup: ночь→...`.
4. **Ф6 + Ф8 вместе**: `apl_lights("auto")` + `apl_popup("auto")` на Bolide —
   оба работают: ночью Ф6 включает свет (глазки выезжают ванильно, Ф8 молчит),
   днём Ф8 моргает; мигок НЕ выключает Ф6 (suppress).
5. Игрок сам трогает свет (клавиша L/радиал) при выключенном auto-свете →
   «игрок сам трогает фары» → auto OFF + WARN (в логе `popup: авто-моргание
   отключено`).
6. `apl_popup("off")` — авто выключен, глазки — штатно.
7. Wigeon — те же шаги (вторая модель).
8. Не-Bolide (например, ETK) — `apl_popup("auto")` → отказ «не поддерживается».
9. Регресс: Ф6 lights (auto/night_state/ручное), Ф7 pet, wheel/pedals,
   CSV 24 колонки.
