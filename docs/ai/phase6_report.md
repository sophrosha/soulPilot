## 2. Архитектура

**GE (`main.lua`) владеет** временем (`core_environment.getTimeOfDay()` — в
electrics времени нет), картой (`getCurrentLevelIdentifier()`), guard pop-up
(`veh.JBeam`), гистерезисом — и шлёт vehicle **числовой target** только при
его смене. **Vehicle (`autopilotLiveLights.lua`) применяет**
`electrics.setLightsState(target)` **с guard** «не зовём, если уже целевое
состояние» (схема ванильного `techCore.handleSetLights`) — «вкл ярко / выкл»
без toggle-циклов, input.event не дёргается.

- **Режимы** (ответы координатора 18.10): день 07:00-20:00 → `day_state`
  (дефолт 1 — ближний как ДХО; 0 — «день без света»); ночь 20:00-07:00 →
  `night_state` (дефолт 1 — ближний; **в конфиге можно 2 — дальний, код это
  читает и включает дальний**). Дальний в auto сам НИКОГДА не включается —
  только из `night_state` либо вручную `apl_lights("far")`.
- **Гистерезис ±15 мин** (обязателен): день→ночь — по границе окна; ночь→день —
  только когда часы вышли из окна, расширенного на ±15 мин; в полосе состояние
  держится — на границе фары не мигают (при направленном времени ночь =
  [20:00 → 07:15]). Шаг опроса — `poll_hz` (1 Гц), штатный хук `M.onUpdate`.
- **Ручное вмешательство**: в auto vehicle следит за
  `lights_state == lastApplied`; расхождение (клавиша L, радиал-меню, салон,
  flash-highbeam) → **«apl_lights: Ручное управление, авто-режим отключен»**,
  фары остаются как поставил игрок — не дерёмся.
- **Pop-up guard**: `JBeam ∈ {bolide, wigeon}` → `apl_lights("auto")` отказывает
  с INFO (Фаза 8); ручные far/near/off работают (то же API, что радиал-меню).
- **Карты**: `lights_by_map.json` → `maps.<level_id>.night_window`; карты вне
  JSON берут РФ-дефолт 20:00-07:00 из `lights.json` (вопрос 5).
- **`apl_mark("тут темнеет")`** → comment = `тут темнеет [19:45]` (время из
  `core_environment`, конвертация как в ge_utils: `((time+0.5)%1)×24`).

## 3. Что правится без кода (`ai/config/`)

- `lights.json`: `poll_hz`, `hysteresis_min`, `day_state`, **`night_state`
  (1→2 — дальний по ночам)**, `night_window.start/end`, `guard.refuse_auto_on_popup`,
  `guard.popup_models`.
- `lights_by_map.json`: `maps.<level_id>.night_window` (id карты печатает
  `apl_lights("status")` — для East Coast ожидается `east_coast_usa`).
- **После правки JSON — заново `apl_lights("auto")`** (конфиг читается при
  включении; `status` показывает свежие значения файла).
- **Быстрая правка из игры** (разрешение координатора 18.10):
  `apl_lights("night_state", 1|2)` или `apl_lights("day_state", 0|1|2)` —
  пишет значение в `modes` lights.json (остальные поля файла сохраняет) и,
  если auto включён, применяет target к машине сразу. Ручная правка файла
  с последующим `auto` тоже работает.
- **Калибровка East Coast (игрок, 18.10)**: метками `apl_mark` на
  east_coast_usa найдены границы: 16:59 день, сумерки 18:35-18:40, к 19:00
  темнота → в `lights_by_map.json` для `east_coast_usa` прописано
  **`start: "18:40", end: "07:00"`**.
- **Калибровка Italy (игрок, 18.10)**: метки: 17:35 вечереет, 18:20 сумерки,
  18:50 темнота → для `italy` прописано **`start: "18:20", end: "07:00"`**.
- **Utah — запись убрана (решение координатора, 18.10, финальная чистка)**:
  карта берёт РФ-дефолт 20:00-07:00; если понадобится своя калибровка —
  метки `apl_mark` на utah и добавить запись обратно.
- Карты, не указанные в `lights_by_map.json`, — РФ-дефолт 20:00-07:00.

## 4. ТЕСТ (выполняет игрок) — БЫСТРЫЙ ПРОГОН (окно калибровано: 18:40-07:00)

Калибровка игрока 18.10 (метки на east_coast_usa): 16:59 — день, сумерки
18:35-18:40, 19:00 — темнота → окно карты **18:40-07:00** внесено в
`lights_by_map.json` (остальные карты — РФ-дефолт 20:00-07:00).
Важно: auto-сценарии — на машине БЕЗ pop-up фар (Gavril T-Series/Covet/ETK);
на Bolide авто-режим намеренно отказывает (guard, Фаза 8) — пункт 8.
Сам `apl_mark` с `[ЧЧ:ММ]` уже подтверждён вашими же метками калибровки.

1. `apl_debug()`.
2. `apl_lights("status")` — map id=`east_coast_usa`, **окно 18:40-07:00 (из
   lights_by_map.json)**, `night_state=1`, конфиг=файл, игровое время.
3. `setTimeOfDay('18:30')` → `apl_lights("auto")` — ожидаем
   `AUTO ON ... → ДЕНЬ, target=1`; фары включены (ближний/ДХО).
4. `setTimeOfDay('18:45')` — ожидаем через ~1 с
   `apl_lights: НОЧЬ (18:45) → target=1` (день и ночь оба =1 → target не
   меняется, фары не мигают — важен сам переход флага в консоли).
5. **Гистерезис вечером**: `setTimeOfDay('18:35')` — перехода «ДЕНЬ» НЕТ
   (полоса ±15 мин: ночь держится до 18:25); `setTimeOfDay('18:20')` —
   ожидаем `apl_lights: ДЕНЬ (18:20) → target=1`.
6. **Гистерезис утром** (утренняя граница не менялась): `setTimeOfDay('21:00')`
   → НОЧЬ; `setTimeOfDay('07:10')` — «ДЕНЬ» НЕТ (полоса до 07:15);
   `setTimeOfDay('07:20')` — ожидаем `apl_lights: ДЕНЬ (07:20)`.
7. **night_state: 2 (дальний)**: ночью с включённым auto (или перед включением)
   ввести из игры **`apl_lights("night_state", 2)`** (быстрая правка конфига —
   пишет lights.json и применяет сразу; ручная правка файла `"night_state": 2`
   + заново `apl_lights("auto")` тоже работает) — ожидаем
   `apl_lights: night_state=2 сохранён в lights.json` и `target → 2`,
   фары — **дальний** (state 2). `apl_lights("status")` → night_state=2.
   Вернуть `apl_lights("night_state", 1)` (ожидаем `target → 1` или
   «target без изменений», если target уже 1).
8. **Pop-up guard**: спавн **Bolide** → `apl_lights("auto")` — ожидаем отказ
   `... pop-up фары: авто-режим НЕ активирован (Фаза 8); far/near/off работают`.
9. **Ручное вмешательство**: ночью с включённым auto щёлкнуть фары клавишей L
   (или радиал-меню) → `apl_lights: Ручное управление, авто-режим отключен`;
   фары остаются в положении игрока; `apl_status()` → `lights: auto=false`.
10. **Ручные режимы**: `apl_lights("far")` → дальний; `apl_lights("near")` →
    ближний; `apl_lights("off")` → выкл — установка только при расхождении
    состояния, без щелчков/циклов.
11. **Не сломано**: `apl_warmup("start")`, `apl_wheel("on")`, `apl_pedals("on")`
    работают как раньше; CSV пишется (24 колонки не менялись); ручное
    переключение фар работает и БЕЗ auto.
12. Смена карты/миссии → `apl_status()` → `lights: auto=false` (auto не
    переживает смену; для прочих карты действует РФ-дефолт 20:00-07:00).

## 5. Ограничения (по исследованию, §1-2 api_research_phase6.md)

- API яркости/dim у фар в 0.39 НЕТ (только 0/1/2; `lightsOverride` отсутствует)
  — «плавный вечер» реализуется только гистерезисом (степенных переходов не
  делаем — запрет координатора).
- Ванильная ночная автоматика (`environment.isNightTime`/`applynightLightsState`)
  управляет только светом сцены (фонари) — фары машины она не трогает,
  конфликта нет.
- Flash-highbeam (долгое нажатие) в auto трактуется как ручное вмешательство —
  авто отключается (это действие игрока).
- Время ставится тестовой командой `setTimeOfDay('ЧЧ:ММ')` либо через UI;
  при недоступном времени (меню) auto не включается (WARN) и тик молчит.
