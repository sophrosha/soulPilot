## 4. Ключевые находки (важно для Фаз 2–7)

1. **Sandbox записи**: io.open → только относительные пути от userPath;
   папки — через `FS:directoryCreate`; реальный путь — `FS:getFileRealPath`.
   Абсолютные пути забыты навсегда.
2. **FILTER_AI — руль ИИ уже сглаживается движком** (`input.lua:643`,
   `smootherPAD:getWithRateCapped(..., 4*rateMult)`), throttle/brake —
   passthrough (`:646`), ассистент `inputStabilization` к FILTER_AI НЕ
   применяется (отдельный слayer). **Открытый вопрос Фазы 4** — варианты
   (a) аддитивно поверх / (b) отключить FILTER_AI для steering /
   (c) свой фильтр вместо движкового: `api_research_phase1.md` §14.
   Эталон для сравнения нашего smoothed — `input.state.steering.val` (RAW).
3. **gear** — `getGearName()` отдаёт и числа (manual/sequential: gearIndex,
   R=−1), и строки ("P/R/N/D/S…", "M1", "S2"). В CSV всегда в кавычках;
   ALLOWED_GEAR в check_csv — вне множества WARN, не FAIL.
4. **Консоль**: GE-Lua исполняет строку как Lua (работает `apl_debug()`).
   Хук `onConsoleExecuteCommand` для «голых» команд без скобок — не проверен
   в игре (дописать по мере надобности).
5. **stop-надёжность**: GE помнит id машины (`csvVehicleId`) и шлёт команды
   через `getObjectByID` fallback, если `getPlayerVehicle(0)` пуст.
