# FAQ

## В игре всё ещё пишет `autopilotLive_main`

1. Закройте игру.
2. Удалите `mods/unpacked/AutopilotLive`.
3. Удалите старую папку `dist` внутри мода.
4. Удалите `mods/db.json`.
5. Запустите `python dev_mode.py`.
6. Запустите игру и убедитесь, что в списке модов есть **soulPilot**.

## После прогрева руль уходит в полный поворот

Покачивание на прогреве ограничено `0.035` в нормализованных единицах. При завершении прогрева sway сбрасывается, а конвейер руля инициализируется от нуля, поэтому ручное положение руля не должно становиться стартовой целью AI.

Если проблема осталась, проверьте `warmup.json`:

```json
"sway": {
  "enabled": 1,
  "amplitude": 0.035
}
```

Не поднимайте амплитуду выше `0.035` для обычной игры.

## Глазки не моргают

- Popup поддерживается только для моделей из конфига:

```json
"models": ["bolide", "wigeon"]
```

- Ночью обычное моргание намеренно отключено.
- Для быстрой проверки задайте в `popup.json`:

```json
"debug_force_blink_delay_s": 5
```

Затем выполните `apl_popup("auto")`. В debug-режиме моргание работает и ночью.

- Если модель правильная, а глаза не двигаются, проверьте в консоли машины сообщения `aplPopup` и состояние `soulPilotLightsCmd`.

## Pet не мурчит

Pet требует запущенный двигатель и неподвижную машину, если AI выключен. Проверьте `pet.json`:

```json
"sound_event": "art/sound/apl_pet.wav"
```

GE-слой вызывает `Engine.Audio.playOnce("AudioGui", ...)` и повторяет попытку с `file:`. Анимацию выполняет vehicle-слой; оба слоя должны быть актуальными.

## Музыка не реагирует

Python-мост пишет:

```text
mods/unpacked/soulPilot/src_music/current.json
```

Запуск:

```powershell
.\ai\venv\Scripts\python.exe src_music\main.py --console
```

Выберите устройство VB-Cable и включите музыку в Spotify. Lua считает данные устаревшими через 0.3 с и безопасно возвращается к нейтральному значению.

## Где мои настройки?

Пользовательские настройки:

```text
%LOCALAPPDATA%\BeamNG\BeamNG.drive\current\settings\mod_settings\soulPilot\
```

Дефолты мода:

```text
src/config/
```

В развёрнутом моде используется корневая папка `config/`. Загрузчик проверяет userPath, затем `src/config`, затем runtime `config`.
